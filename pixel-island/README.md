# 🏝️ 像素小島 Pixel Isle

一座有瀑布的像素風小島：貓咪、狐狸、薩摩耶住在這裡，你可以開船出海，看看今天會遇見什麼。

這個資料夾是**獨立的小遊戲**，純 HTML + JavaScript，不依賴主專案的 Next.js，也不需要安裝或建置。

## 線上遊玩與分享

部署後的網址：**https://a65041230.github.io/infinite-aeon-campaign/**

由 `.github/workflows/pixel-island-pages.yml` 自動部署：每次 `main` 分支裡的 `pixel-island/` 有變動，就會重新發佈到 GitHub Pages。
第一次需要到 GitHub 的 **Settings → Pages → Build and deployment → Source** 選「**GitHub Actions**」。

## 怎麼玩

直接用瀏覽器打開 `index.html` 即可（雙擊檔案就能玩）。
也可以在這個資料夾開一個靜態伺服器：

```bash
npx http-server pixel-island
```

| 按鍵 | 功能 |
| --- | --- |
| `WASD` / 方向鍵 | 走路；在船上時 ←→ 轉舵、↑ 加速、↓ 減速／倒退 |
| `E` / 空白鍵 | 互動：摸動物、上下船、點營火、搖樹、按門鈴、翻石頭… |
| `F` | 釣魚（面向海或水潭；浮標動了再按一次） |
| `H` | 船上鳴笛／岸上吹口哨叫動物 |
| `N` | 切換白天／夜晚 |
| `J` | 圖鑑 |
| `M` | 音樂開關 |
| 滑鼠／觸控 | 點地面走過去、點海面讓船自動開過去、點夜空的流星許願 |

手機會自動顯示方向鍵與 A／B 按鈕。

## 島上有什麼

- **動物**：貓咪（愛睡覺、聽到門鈴會回家）、狐狸（很害羞，要站著不動等牠靠近）、薩摩耶（活潑、會暴衝、看到海鷗會叫）。
  摸摸牠們或餵魚，牠們會跟著你，甚至一起跳上船。夜裡營火亮著時，大家會聚在火邊睡覺。
- **地形**：高台上的小河流成瀑布，落進水潭再化成小溪流入海；東側有石階可以爬上高台。碼頭、木屋、營火、告示牌、東北方小島上的燈塔。
- **船**：可以掌舵的小帆船，有慣性、轉舵、撞岸回彈、船尾浪花，畫面下方有舵輪與速度表。
- **隨機事件**（每 20～35 秒一次，或按 🎲）：海豚、鯨魚、海龜、水母、魚群、海鷗、魟魚、海獺、漂流瓶、漂流寶箱、雷陣雨、海霧、彩虹，以及夜晚限定的流星雨、極光、螢光海。
- **日夜循環**：約 4 分鐘一天，夜晚有營火、窗光、船燈、燈塔光束、螢火蟲與海面星光倒影。
- **圖鑑**：30 種生物、天氣、漂流物和漁獲，進度存在瀏覽器裡。
- **音效**：全部用 Web Audio 即時合成（貓叫、狗叫、狐狸叫、浪聲、瀑布、雨聲、蟲鳴、鯨魚歌、鐘聲…），加上會隨日夜切換的生成式晶片音樂。

## 檔案結構

```
pixel-island/
├── index.html      頁面與介面
├── style.css       像素風介面樣式
└── js/
    ├── util.js       數學、噪聲、顏色、存檔小工具
    ├── audio.js      合成音效、環境音與背景音樂
    ├── sprites.js    像素精靈圖（字元圖與程序生成）
    ├── world.js      地形生成與逐像素水面動畫
    ├── entities.js   玩家、船、動物、螃蟹、粒子
    ├── creatures.js  海洋生物、隨機事件、圖鑑、釣魚
    ├── ui.js         提示、對話框、圖鑑、觸控按鈕
    └── main.js       輸入、互動、光影、主迴圈
```
